## 研究问题

我在 InfMasking 上增加全局原型关系轮廓，使掩码视图预测完整视图对原型的软分配，目标是提高多模态协同信息的保留能力。当前主要观察 Trifeatures S 组的 synergy 任务。

总损失为：

$$
\mathcal{L}
=
\mathcal{L}_{\mathrm{InfMasking}}
+
\alpha\mathcal{L}_{\mathrm{profile}}.
$$

当前候选配置为单向预测、$K=128$、queue=1024、$\alpha=0.25$。

## 2026-09-19 代码复核结论

复核发现四个会影响正式实验可信度的问题：

1. 旧版所谓 EMA 实际执行的是原型向量加权累加后归一化，没有计算 assignment-weighted centroid，也不符合文档中的 EMA 公式；
2. UniGIR 初始化原型时消耗全局 PyTorch 随机数，导致相同 seed 的 Baseline 和 UniGIR 后续数据打乱、随机增强不一定使用相同随机流；
3. 入口只设置 Torch 和 NumPy seed，没有统一设置 Python `random` 和 DataLoader worker seed；
4. linear probing 每个 epoch 使用的 `val_dataloader` 实际对应官方 test split。用该指标 early stopping 或选择最佳 checkpoint 会造成测试泄漏。

以上问题已经修复：

- 原型按 assignment-weighted batch centroid 做真正的 EMA 更新；
- 原型使用独立随机生成器初始化，不改变全局随机状态；
- 训练入口使用 `seed_everything(seed, workers=True)`；
- 正式训练固定 epoch，不使用 early stopping，只保存最后一个 checkpoint；
- linear probing 默认改为 `by_fit`，训练结束后只在官方测试集上评测一次；
- 新增预测分布熵、目标分配熵、目标置信度和原型平均绝对余弦相似度；
- 默认配置改为 $K=128$、单进程、单设备、确定性训练和 `num_workers=0`；
- 新增 `.gitignore`，避免误提交约 2.2 GB checkpoint 和运行日志。

## 历史结果的有效范围

修复前，seed=42 和 seed=7 的 4 epoch 结果显示 synergy acc@1 和 synergy ROC AUC 的平均变化为 +0.028 和 +0.020，四任务平均 acc@1 只变化 +0.001。

这些结果仍能说明旧实现产生过弱信号，但不能作为修复后 UniGIR 的正式结果，原因有三点：原型更新公式已经改变，Baseline 和 UniGIR 的随机流没有严格配对，旧流程每个 epoch 查看了官方测试集。后续表格必须将它们标为预修复探索结果，不能与修复后的结果直接求均值或比较。

旧文档中用 target usage entropy 接近 1 和 active prototypes 接近 $K$ 证明没有塌缩，这个结论过强。Sinkhorn 本来就会强制目标分配接近均匀，这两个指标主要证明均衡约束生效。正式判断还需要结合 prediction usage entropy、target confidence、prototype similarity 和下游指标。

## 数据规模复核

`max_size` 表示采样的图像对数量，不是基础图片数量。当前数据目录有 2400 张训练基础图和 200 张测试基础图，实际 pair dataset 为：

| 设置 | pair 数 | 覆盖基础图 |
|---|---:|---:|
| S 组 train，`max_size=1024` | 1024 | 1367 / 2400 |
| S 组 train，`max_size=1e4` | 10000 | 2399 / 2400 |
| S 组 test，`max_size=1e4` | 404 | 198 / 200 |
| probing train，`biased=false` | 10000 | 2399 / 2400 |
| probing test，`biased=false` | 4094 | 200 / 200 |

因此正式主实验的规模应记为 10000 个训练 pair。2400 表示训练基础图片数。按 batch size 64 计算，每个 epoch 约 157 个训练 step，单个 100 epoch run 约 15700 个训练 step。

## G1 判断标准

- Strong Go：3/3 个 seed 的 synergy ROC AUC 高于各自 Baseline，平均绝对提升至少 0.01；
- Weak Go：至少 2/3 个 seed 提升，且三 seed 平均变化为正；
- 四任务平均 acc@1 的三 seed 平均下降不超过 0.01；
- profile prediction usage entropy、target confidence 和 prototype similarity 不显示退化；
- 所有方法使用固定 epoch、相同数据配对、相同 seed 和相同最终评测流程。

0.01 是 pilot 的工程筛选阈值，不是统计显著性结论。三 seed 只够做方向判断，正式论文仍要报告每个 seed、均值、标准差和配对变化。
