# UniGIR 研究想法与方法

更新时间：2026-09-19

## 1. 研究出发点

InfMasking 通过无限掩码让模型从不完整的多模态输入中恢复协同信息。它的主要损失在 batch 内建立样本关系，因此模型能够学习样本之间的局部匹配，但不一定能够表示样本在更大数据集合中的结构位置。

UniGIR 研究的问题是：完整视图和掩码视图除了样本级匹配，还应在一组参照点上拥有相近的关系轮廓。这里的参照点是原型，样本对所有原型的软分配构成一个关系轮廓。当前方法概念写作 **Global Relational Structure Distillation under Multimodal Masking**。

原始想法曾经把测地距离作为主要创新。调研后发现 GeoMM（CVPR 2025）已经研究了测地距离、多层聚类图和最短路径，因此现在把研究重点放在全局关系轮廓与协同信息的结合上。测地距离保留为后续可选的度量增强，不作为当前方法的首要贡献。论文贡献需要围绕关系结构在掩码下的保留及其与协同信息的联系展开，不能把 Prototype、Sinkhorn、EMA 和 Queue 的组合本身写成主要创新。

## 2. UniGIR V2 的数据流

对于一个 batch 的两个增广，InfMasking 产生完整表征和多个掩码表征：

$$
z_a^{\mathrm{full}},\quad z_b^{\mathrm{full}},\quad
\{m_{a,t}\}_{t=1}^{T},\quad \{m_{b,t}\}_{t=1}^{T}.
$$

这些表征经过投影头后位于同一个 256 维空间。UniGIR 在这个投影空间中维护 $K$ 个原型：

$$
P=\{p_1,p_2,\ldots,p_K\},\qquad p_k\in\mathbb{R}^{d}.
$$

当前默认 $K=128$，$d=256$。原型初始化使用独立随机生成器，seed 与实验 seed 一致，但不会推进模型训练使用的全局随机状态。

## 3. Sinkhorn 均衡分配

完整表征和原型之间的相似度为：

$$
s_{ik}=z_i^{\mathrm{full}}p_k^{\mathsf T}.
$$

直接对相似度使用 softmax，容易使大量样本集中到少数原型。当前实现将 batch 和 feature queue 中的完整表征一起组成分配矩阵，再进行 Sinkhorn-Knopp 迭代：

$$
Q^{(0)}=\exp\left(\frac{S}{\varepsilon}\right).
$$

每轮先进行行归一化，再进行列归一化，最后重新进行行归一化，得到每个样本对 $K$ 个原型的轮廓 $q_i$。$q_i$ 从计算图中分离，作为完整视图提供的伪标签。

Sinkhorn 的作用是让一批样本尽量均匀地使用原型，减少分配塌缩。它本身来自 SwAV，UniGIR 的区别在于把它用于完整多模态视图和掩码多模态视图之间的轮廓预测。

## 4. 跨 batch feature queue

如果只使用当前 batch，轮廓仍然受到 batch 采样的影响。当前实现保存最近的完整视图表征：

$$
\mathcal{Q}_t
=
\operatorname{Queue}
\left(
z_{t-L+1}^{\mathrm{full}},\ldots,z_t^{\mathrm{full}}
\right),
$$

其中 $L$ 是 queue 长度，UniGIR 默认 $L=1024$。计算当前 batch 的轮廓时，将 queue 和当前 batch 拼接后进行 Sinkhorn，只取当前 batch 的分配作为监督信号。queue 使用环形写入，验证阶段不更新。

这个设计可以让轮廓看到更多历史特征，但它仍然不是全量训练集的精确关系轮廓。是否需要更大的 queue，属于后续实验问题。

## 5. EMA 原型更新

原型不接收梯度。先根据软分配计算第 $k$ 个原型在当前 batch 中的加权中心：

$$
\bar z_k
=
\frac{\sum_i q_{ik}z_i^{\mathrm{full}}}
{\sum_i q_{ik}}.
$$

再进行指数移动平均并归一化：

$$
p_k
\leftarrow
\operatorname{Normalize}
\left(
(1-\eta)p_k+\eta\bar z_k
\right).
$$

当前默认更新率为 $\eta=0.05$。两个增广的完整视图合并后只更新一次原型，避免先后更新造成顺序偏差。验证阶段不更新原型和 queue。

2026-09-19 以前的实现使用 $p_k+\eta\sum_i q_{ik}z_i$ 后归一化，没有除以分配质量，也没有 $(1-\eta)$ 项，因此不能称为严格 EMA。历史实验属于修复前结果。

## 6. Profile loss

第 $t$ 个掩码视图对原型的预测分布为：

$$
p_{i,t}
=
\operatorname{softmax}
\left(
\frac{m_{i,t}P^{\mathsf T}}{\tau}
\right).
$$

完整视图提供轮廓 $q_i$，掩码视图通过 KL 散度预测该轮廓：

$$
\mathcal{L}_{\mathrm{profile}}
=
\frac{1}{T}
\sum_{t=1}^{T}
\operatorname{KL}(q_i\|p_{i,t}).
$$

总损失采用显式权重：

$$
\mathcal{L}
=
\mathcal{L}_{\mathrm{InfMasking}}
+
\alpha\mathcal{L}_{\mathrm{profile}}.
$$

当前配置使用 $\alpha=0.25$。这样可以直接比较不同权重，不受原有损失项数量影响。

## 7. 当前实现与限制

已实现：

- Sinkhorn 均衡分配；
- EMA 原型更新；
- 跨 batch feature queue；
- profile loss 的显式权重；
- profile KL、target usage entropy 和 active prototypes 统计；
- prediction usage entropy、target confidence 和 prototype mean absolute cosine；
- 关闭 profile 分支时保留原始 InfMasking 路径。

仍需验证：

- queue 是否能带来比单 batch 更稳定的轮廓；
- $K$ 和 $\alpha$ 的合理范围；
- 单向预测是否优于双向预测；
- profile 目标是否与 InfMasking 原有目标重复；
- profile 指标的提升能否转化为 synergy 下游增益。

当前最大的科学风险是辅助任务成为伪目标：profile loss 和 profile accuracy 可以持续改善，但这些变化未必带来 downstream synergy 或真实任务收益。后续机制实验必须比较正常目标与 shuffled profile。若两者的下游结果接近，则现有证据不支持关系轮廓假设。

`queue=0` 时，Sinkhorn 只使用当前 batch，因此它在现有实现中已经是 batch-only relational profile。No Queue 与 Batch-only 不能重复列为两项消融；若要同时报告，必须先给出不同的操作定义。

MOSI 是低成本真实迁移候选。它有 train/validation/test 划分，也在 InfMasking 原工作中使用，但任务标签是情感分类标签。MOSI 的提升只能支持真实任务效用，不能单独证明 synergy 机制。

需要注意，Sinkhorn 会主动均衡 target assignment，因此 target usage entropy 接近 1、active prototypes 接近 $K$ 主要说明均衡约束在工作，不能单独证明表示没有塌缩。后续判断必须同时查看预测分布熵、目标置信度、原型相似度和下游指标。
