## 2026-09-19：代码复核与修复后冒烟

实验编号：EXP-017、EXP-018。

状态：已完成。没有启动长训练，没有残留 Python 进程。

### 复核发现

- 旧版 `_update` 不是严格 EMA；
- 原型初始化消耗全局 Torch RNG，影响同 seed 的配对公平性；
- 入口没有统一设置 Python `random` 和 DataLoader worker seed；
- 逐 epoch probing 使用官方 test split，不能用于 early stopping 或 checkpoint 选择；
- target usage entropy 和 active prototypes 受 Sinkhorn 均衡约束影响，不能单独证明没有塌缩；
- 项目没有 `.gitignore`，22 个 checkpoint 约占 2.19 GB，存在误提交风险。

### 实际修复

- 使用 assignment-weighted centroid 做 EMA；
- 原型使用独立 generator 初始化；
- 使用 `seed_everything(seed, workers=True)`；
- 默认固定 epoch、`probe_frequency=by_fit`、关闭 early stopping、只保存最后 checkpoint；
- 新增 prediction usage entropy、target confidence 和 prototype mean absolute cosine；
- 默认 $K$ 改为 128，默认单进程、单设备、确定性训练；
- 新增 `.gitignore` 和修复版 GPU pilot 脚本。

### 测试
