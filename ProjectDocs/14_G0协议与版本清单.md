## 3. 后续实验协议

### G1 开发 pilot（已完成）

G1 继续使用已有 development split，用于判断修复后的 UniGIR 是否值得进入机制验证。数据生成 seed 不改变，模型 seed 与 pair 采样 seed 分开记录。

| 项目 | 固定设置 |
|---|---|
| 数据组 | S，`biased=true` |
| pair 数 | `max_size=1024` |
| batch size | `64` |
| embedding | `256` |
| mask 数 | `3` |
| mask ratio | `0.7` |
| 训练长度 | `10` epoch |
| 模型 seed | `42`、`7`、`123` |
| 对照 | InfMasking Baseline、UniGIR 单向 profile |
| UniGIR 原型数 | $K=128$ |
| feature queue | `1024` |
| profile loss 权重 | $\alpha=0.25$ |
| cross profile | 关闭 |
| probing | 固定 epoch 后执行一次，不按中间结果选 checkpoint |
| 主要指标 | synergy ROC AUC |
| 保护指标 | synergy acc@1、四任务平均 acc@1、四任务平均 ROC AUC 和三个单任务指标 |

Baseline 与 UniGIR 必须使用相同模型 seed、相同 development split、相同 pair 采样 seed、相同训练预算和独立实验目录。

### G1 判断

- Strong Go：3/3 个 seed 的 synergy ROC AUC 提升，平均绝对提升至少 0.01，四任务平均 acc@1 下降不超过 0.01，诊断指标没有退化；
- Weak Go：至少 2/3 个 seed 提升，三 seed 平均变化为正，四任务平均 acc@1 下降不超过 0.01；
- Uncertain：指标方向冲突或只有一个 seed 提升；
- No-Go：平均 synergy ROC AUC 不提升，或其他任务普遍下降，或 profile 学习与下游结果没有联系。

实际结果：seed=42、7、123 的 synergy ROC AUC 变化分别为 `+0.001`、`+0.022`、`-0.016`；2/3 个 seed 提升，三 seed 平均约 `+0.002`，四任务平均 acc@1 平均约 `+0.014`。因此 G1 达到 Weak Go，未达到 Strong Go。G2 和 G3 已完成，后续正式确认执行顺序与判定条件见 `ProjectDocs/15_G4正式确认协议.md`。
