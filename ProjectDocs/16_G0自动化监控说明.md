只有前一项状态为成功，且当前 GPU 没有未知计算进程时，watchdog 才会注册下一项计划任务。训练任务本身仍由 `winpc_schedule_experiment.ps1` 脱离 SSH 会话运行。

## 停止条件

watchdog 检查每个运行的 `status.log`、stdout、stderr 和 `last.ckpt`。出现以下任一情况时，动作记为 `STOP`，后续任务不再自动注册：

1. 日志出现非零 `EXIT_CODE`；
2. 日志出现 `CUDA error`、CUDA out of memory、Traceback、RuntimeError 或其他明确异常；
3. 任务以 `EXIT_CODE=0` 结束，但独立 checkpoint 目录中没有 `last.ckpt`；
4. `nvidia-smi` 检测到未知 GPU 计算进程，或者 GPU 检查本身失败；
5. 后面的任务已经运行或完成，而前面的任务还没有成功，说明固定顺序被绕过。

Windows 的桌面合成、输入法、搜索、Edge 和其他系统图形进程会被识别为桌面进程并忽略。Python、Torch 和未知路径的计算进程不会被忽略。

checkpoint 缺失检查针对已经写入 `END` 的任务。训练刚启动、尚未完成第一个 epoch 时，watchdog 会等待，不会因为暂时没有 `last.ckpt` 误停任务。

## 状态和通知文件

watchdog 在 `winpc_logs` 下写入：

| 文件 | 用途 |
|---|---|
| `winpc_g4_watchdog.status.json` | 最近一次完整状态，包括动作、停止原因、GPU 进程和六项运行状态 |
| `winpc_g4_watchdog.events.log` | 只记录动作变化、停止事件、启动请求和全部完成事件 |
| `winpc_g4_watchdog.state.json` | 保存上一次动作，避免每 15 分钟重复写相同通知 |
| `winpc_g4_watchdog.dryrun.*` | DryRun 测试产生的临时记录，不参与正式判断 |

轻薄本可以通过 SSH 读取：

```powershell
ssh winpc powershell.exe -NoProfile -Command "Get-Content -LiteralPath 'C:\Users\liangyelian\work\InfMasking_desktop_20260923\winpc_logs\winpc_g4_watchdog.status.json'"
```

如果状态中的 `Action` 为 `STOP`，先查看 `Detail` 和 `StopReasons`，不要手动启动后续任务。训练完成后由 Codex 读取六组结果、更新实验记录、结果分析和导师汇报。
