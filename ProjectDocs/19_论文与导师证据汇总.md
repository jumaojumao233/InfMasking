# UniGIR 论文与导师证据汇总

更新时间：2026-09-25  
用途：整理当前已经完成的实验，作为论文初稿、导师阶段汇报和后续实验决策的共同依据。

## 一、研究问题和当前方法

InfMasking 通过遮挡输入的一部分内容，要求模型从剩余视图中学习表征。当前改进 UniGIR 在这个训练过程中加入 profile 目标：模型从一个视图的表征预测另一个视图的关系轮廓。当前主配置为单向 profile、$K=128$ 个 prototype、queue size 为 1024、profile loss weight 为 $\alpha=0.25$。

当前要回答的问题是：profile 目标能否在不破坏原有信息的情况下，提高模型对多模态协同信息的学习能力。G0 的主要指标是 `synergy ROC AUC`，`unique2` 是保护指标，用来检查模型是否牺牲纹理信息换取协同信息。

截至 2026-09-25，已经完成以下证据链：

1. G0 三个 model seed 的 Baseline/UniGIR 正式配对实验；
2. unique2 的随机变换和固定变换 checkpoint 配对评测；
3. 与 unique2 测试协议一致的逐样本 profile 和表示距离诊断；
4. MOSI 三个 seed 的 profile loss weight 对照。

## 二、当前可以下的结论

| 结论 | 直接证据 | 当前判断 | 可以写到论文中的程度 |
|---|---|---|---|
| UniGIR 提高了 G0 的 synergy ROC AUC | 三个 seed 的差值均为正，平均差值为 `+0.026` | 主要指标方向稳定 | 可以写为三 seed 短预算实验中的稳定正向结果 |
| UniGIR 没有带来整体多任务 acc@1 的稳定提升 | 四任务平均 acc@1 的三 seed 平均差值为 `-0.010` | 主要指标与整体指标发生冲突 | 必须同时报告，不能只报告 synergy |
| unique2 出现持续退化 | 训练末 probing 中三个 seed 的 unique2 acc@1 均下降，平均差值为 `-0.053`；固定变换配对评测平均差值为 `-0.068502` | 保护指标存在稳定风险 | 可以写为当前方法的明确代价或限制 |
| 退化集中在部分 texture 类别 | `pluses`、`stripes`、`zigzags` 在训练末类别准确率中 3/3 seed 下降；固定变换下 `stripes` 和 `pluses` 也在 3/3 seed 下降 | 退化具有类别集中趋势 | 可以作为误差分析结果，不能直接当作机制证明 |
| profile 分支确实产生了可测信号 | profile accuracy 为 `0.775—0.813`，active prototypes 为 `93.6—99.0/128`，prediction usage entropy 为 `0.932—0.938` | 没有看到明显 prototype collapse | 可以写为训练状态诊断 |
| 当前没有证据证明 profile 目标直接造成某一类错误 | `pluses` 的 profile accuracy 较高且 profile KL 较低，但 unique2 仍下降；masked distance 也没有整体变差 | 原因仍是描述性假设 | 不能写成因果结论 |
| 降低 profile loss weight 没有稳定改善真实任务表现 | MOSI 三 seed 中 $\alpha=0.125$ 的平均 acc@1/ROC AUC 为 `0.602/0.677`，低于 $\alpha=0.25$ 的 `0.621/0.688` | 保留 $\alpha=0.25$ | 可以作为停止该方向搜索的依据 |

因此，当前 G0 状态仍为 **Uncertain**。UniGIR 对 synergy 的正向结果已经出现三 seed 一致性，但 unique2 的退化也在三 seed 和固定变换复核中出现。当前证据支持继续分析和写作，不支持把 UniGIR 直接表述为整体性能稳定提升的方法。

### 3.1 主要指标和保护指标的关系

| 指标 | 三 seed 中 UniGIR 提升次数 | 三 seed 平均差值 | 解释 |
|---|---:|---:|---|
| synergy ROC AUC | 3/3 | +0.026 | 主要指标方向稳定 |
| synergy acc@1 | 1/3 | +0.010 | 和 ROC AUC 不完全同向，受阈值影响更明显 |
| unique2 acc@1 | 0/3 | -0.053 | 保护指标持续退化 |
| unique2 ROC AUC | 0/3 | -0.012 | 不只是分类阈值造成的 acc@1 变化 |
| 四任务平均 acc@1 | 1/3 | -0.010 | 没有形成整体 acc@1 收益 |
| 四任务平均 ROC AUC | 2/3 | +0.003 | 总体变化很小，不能替代任务级分析 |

这个结果说明 profile 目标可能帮助模型提取协同信息，同时改变了对纹理信息的保留方式。表格可以支持任务间权衡的描述，但还不能支持具体的因果机制。

## 四、unique2 退化的两套配对评测

训练末 probing 给出了退化方向。为了排除测试过程中的偶然变换影响，我又对六个 checkpoint 做了只读配对评测。同一 model seed 的 Baseline 和 UniGIR 使用相同的 `y_true` 顺序，差值仍按 UniGIR 减 Baseline 计算。

| model seed | 随机变换 Baseline | 随机变换 UniGIR | 随机变换差值 | 固定变换 Baseline | 固定变换 UniGIR | 固定变换差值 |
|---:|---:|---:|---:|---:|---:|---:|
| 42 | 0.726863 | 0.713574 | -0.013289 | 0.769815 | 0.719506 | -0.050308 |
| 7 | 0.766967 | 0.731134 | -0.035833 | 0.829853 | 0.791172 | -0.038681 |
| 123 | 0.776697 | 0.684860 | -0.091837 | 0.826531 | 0.710014 | -0.116516 |
| 三 seed 平均 | 0.756842 | 0.709856 | -0.046986 | 0.808733 | 0.740231 | -0.068502 |

固定变换为 `Resize(256) + CenterCrop(224)`。两套评测的差值都为负，固定变换下退化幅度更大，因此当前可以排除随机裁剪是主要假象。这里的绝对 acc@1 只用于同一评测协议内的 Baseline/UniGIR 配对比较，不能与训练末的 `by_fit` 数值直接合并。

## 五、逐样本 profile 和表示诊断

诊断使用与 unique2 probe 完全一致的 `Sup + biased=false + task=unique2` 测试集合，固定变换为 `Resize(256) + CenterCrop(224)`，每个 seed 为 4214 个 pair。六项导出均为只读前向，没有调用 `trainer.fit`，没有修改 checkpoint。

| texture | profile acc 均值 | profile KL 均值 | target confidence 均值 | target entropy 均值 | masked distance 差值均值 |
|---|---:|---:|---:|---:|---:|
| solid | 0.7151 | 0.4128 | 0.4977 | 0.2866 | -0.0022 |
| stripes | 0.7493 | 0.4496 | 0.5709 | 0.2615 | -0.0014 |
| grid | 0.7475 | 0.4078 | 0.5532 | 0.2615 | -0.0036 |
| hexgrid | 0.7532 | 0.4352 | 0.5737 | 0.2578 | -0.0018 |
| dots | 0.7312 | 0.4255 | 0.5534 | 0.2670 | -0.0043 |
| noise | 0.7440 | 0.4099 | 0.5655 | 0.2541 | -0.0030 |
| triangles | 0.7633 | 0.4138 | 0.5639 | 0.2576 | -0.0050 |
| zigzags | 0.7386 | 0.3992 | 0.5778 | 0.2428 | -0.0034 |
| rain | 0.7353 | 0.4255 | 0.5441 | 0.2707 | -0.0054 |
| pluses | 0.7762 | 0.3756 | 0.5665 | 0.2487 | -0.0054 |

三 seed 的总体 masked distance 差值分别为 `-0.0011`、`-0.0046` 和 `-0.0049`，平均约为 `-0.0035`。这里的差值定义为 $1-\cos(z_{masked},z_{full})$ 的 UniGIR 值减去 Baseline 值；负值表示 masked 表征与完整表征的余弦距离变小。

| 诊断问题 | 观察到的结果 | 当前能否支持 |
|---|---|---|
| profile 分支是否工作 | profile accuracy 为 `0.775—0.813` | 可以支持 profile 输出包含可测预测信号 |
| 是否发生明显 prototype collapse | active prototypes 为 `93.6—99.0/128`，prediction usage entropy 为 `0.932—0.938` | 暂未看到明显 collapse |
| unique2 退化是否因为 pluses 上 profile 没学到 | `pluses` profile acc 为 `0.7762`，profile KL 为 `0.3756`，均不属于最差水平 | 不支持这个简单解释 |
| masked 表征是否普遍偏离完整表征 | 大多数类别的 masked distance 差值为负 | 不支持普遍偏离的解释 |
| profile 是否造成 texture 线性可分性下降 | unique2 退化与表示几何变化同时出现 | 只能作为待检验假设，不能写成因果结论 |

当前最稳妥的机制表述是：profile 目标改变了 masked 与完整表征之间的几何关系，且这种变化可能与 texture 线性分类需要的方向发生任务权衡。这个表述属于基于现有诊断的研究假设，尚未经过显著性检验、梯度归因或受控目标拆分实验。

第一轮 402 pair 的导出使用了自监督 `biased=true` 数据模块，与 unique2 probe 协议不一致，已经废弃。当前只采用修正后的 4214 pair 结果。

## 六、MOSI profile loss weight 对照

MOSI 三个 seed 均使用 10 epoch、batch size 32、queue=1024、$K=128$、单向 profile 和 `by_fit` probing。唯一变量是 profile loss weight，从 $\alpha=0.25$ 改为 $\alpha=0.125$。

| model seed | Baseline acc@1 / AUC | $\alpha=0.25$ acc@1 / AUC | $\alpha=0.125$ acc@1 / AUC | $\alpha=0.125-\alpha=0.25$ |
|---:|---:|---:|---:|---:|
| 42 | 0.573 / 0.655 | 0.641 / 0.704 | 0.641 / 0.715 | 0.000 / +0.011 |
| 7 | 0.559 / 0.627 | 0.587 / 0.642 | 0.607 / 0.664 | +0.020 / +0.022 |
| 123 | 0.608 / 0.671 | 0.636 / 0.717 | 0.557 / 0.652 | -0.079 / -0.065 |
| 三 seed 平均 | 0.580 / 0.651 | 0.621 / 0.688 | 0.602 / 0.677 | -0.020 / -0.011 |

$\alpha=0.125$ 的平均结果仍高于 Baseline，但低于 $\alpha=0.25$；seed=123 的两个指标均明显下降。因此，降低 profile 约束强度没有稳定改善真实任务表现，也没有消除 seed 方差。MOSI 没有 G0 的 unique2 标签，所以这项对照不能直接解释 texture 类别退化。

当前配置保留 $\alpha=0.25$。loss weight、queue 和 prototype 的组合搜索已经停止。

## 七、论文中可以写什么，不能写什么

| 可以写 | 依据 | 需要同时补充的限制 |
|---|---|---|
| UniGIR 在 G0 三个 seed 上提高 synergy ROC AUC，平均提升 `+0.026` | 三个 seed 的差值为 `+0.027`、`+0.037`、`+0.014` | 这是 10 epoch、当前数据和当前协议下的结果 |
| UniGIR 对 unique2 造成稳定代价 | 训练末、随机变换和固定变换评测方向一致 | 需要报告任务级和类别级结果，不能只给平均数 |
| 退化主要集中在部分 texture 类别 | `pluses`、`stripes`、`zigzags` 多次复核均有下降 | 这是误差分布描述，不是机制证明 |
| profile 分支处于工作状态且没有明显 prototype collapse | profile-only 统计和 active prototype 统计 | 聚合统计不能排除局部类别问题 |
| $\alpha=0.25$ 是当前更合适的主配置 | MOSI 三 seed 平均优于 $\alpha=0.125$ | MOSI 只有真实情感任务，不能替代 G0 |

| 当前不能写 | 原因 |
|---|---|
| UniGIR 整体性能稳定提升 | 四任务平均 acc@1 平均下降 `-0.010`，unique2 在三 seed 均下降 |
| profile 目标导致了 pluses 或 stripes 的具体混淆 | 现有结果只有配对 recall 和表示统计，没有受控因果实验 |
| prototype collapse 是 unique2 退化原因 | active prototypes 和 usage entropy 没有显示明显 collapse |
| MOSI 证明了 G0 texture 退化的机制 | MOSI 没有 unique2 标签，任务结构不同 |
| 100 epoch 会继续放大 synergy 收益 | 当前没有长训练证据，且保护指标已经出现退化 |
| UniGIR 已经达到 Strong Go | 主要指标满足正向要求，但保护指标冲突，协议判定为 Uncertain |
