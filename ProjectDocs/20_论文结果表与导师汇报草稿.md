# UniGIR 论文结果表与导师汇报草稿

更新时间：2026-09-25  
用途：把已经完成的 G0、unique2 诊断和 MOSI 对照整理成论文结果表及导师汇报初稿。所有数字均来自现有归档，不包含新训练结果。

## 一、论文结果段落草稿

我在 InfMasking 的 masked-view 训练基础上加入了单向 profile 目标，用一个视图的表征预测另一个视图的关系轮廓。当前配置使用 $K=128$ 个 prototype、queue size 为 1024，profile loss weight 为 $\alpha=0.25$。我先在开发实验中固定了训练协议，再使用封存的 G0 数据比较 Baseline 和 UniGIR。

G0 使用三个 model seed，训练预算为 10 epoch。主要指标 synergy ROC AUC 在三个 seed 上都提高，差值分别为 `+0.027`、`+0.037` 和 `+0.014`，平均差值为 `+0.026`。这说明 profile 目标对协同信息的影响方向具有一定稳定性。

同时，unique2 acc@1 在三个 seed 上都下降，平均差值为 `-0.053`；四任务平均 acc@1 的平均差值为 `-0.010`。对六个 checkpoint 做固定变换下的只读配对评测后，unique2 acc@1 的平均差值仍为 `-0.068502`。因此，当前结果支持任务间权衡的判断，不能写成 UniGIR 带来了整体多任务性能提升。

为了检查退化是否来自 profile 分支没有学习到有效关系，我又使用与 unique2 probe 对齐的 4214 个测试 pair 做了逐样本诊断。profile 分支有可测预测信号，active prototypes 为 `93.6—99.0/128`，没有看到明显 prototype collapse。`pluses` 的 profile accuracy 均值为 `0.7762`，但该类别的 unique2 recall 仍然下降。因此，现有结果不能把 texture 退化直接归因于 profile 预测失败或原型塌缩。

在 MOSI 上，我保持数据、seed、训练预算、queue、prototype 数量和 probing 协议不变，只把 $\alpha$ 从 `0.25` 改为 `0.125`。三 seed 平均 acc@1/ROC AUC 从 `0.621/0.688` 降为 `0.602/0.677`，说明降低 profile 权重没有稳定改善真实任务表现。当前主配置保留 $\alpha=0.25$，G0 阶段性结论记为 `Uncertain`。

## 八、给导师的阶段汇报草稿

### 已完成的工作

我已经完成了 G0 封存数据上的三 seed 正式实验。Baseline 和 UniGIR 使用相同的数据、pair sampling seed、model seed 和训练预算，六项任务均成功结束并生成 checkpoint。随后我完成了 unique2 的随机变换和固定变换配对评测，确认退化方向没有消失；又完成了与 unique2 probe 对齐的逐样本 profile 和表示诊断，检查了 profile accuracy、profile KL、prototype 使用分布和 masked-to-full 表征距离。

在真实任务上，我完成了 MOSI 三 seed 的 profile loss weight 对照。降低 $\alpha$ 到 `0.125` 后，平均结果低于当前配置 `0.25`，所以目前保留 $\alpha=0.25$。winpc 上的训练和评测由独立目录、checkpoint 和 watchdog 管理，轻薄本只负责 SSH、日志、邮件和文档。

### 当前结果

G0 的 synergy ROC AUC 在三个 seed 上均提升，平均提升 `+0.026`。unique2 acc@1 在三个 seed 上均下降，平均下降 `-0.053`；固定变换配对评测的平均差值为 `-0.068502`。退化集中在 `pluses`、`stripes` 和 `zigzags` 等 texture 类别。profile 分支有可测信号，没有明显 prototype collapse，但现有诊断仍不能证明具体的因果机制。

### 当前判断

我把 G0 记为 `Uncertain`。当前证据支持这样表述：UniGIR 在协同信息指标上有稳定的正向方向，同时对部分纹理信息产生了代价。它还不能被表述为整体多任务性能稳定提升的方法。后续工作先整理论文表格和图，不启动 100 epoch，也不继续搜索 loss weight、queue 或 prototype。

### 拿不准的点

1. G0 的主结论采用哪种表述：
   - A：主要指标稳定提升，但 unique2 保护指标持续退化，整体记为 `Uncertain`；
   - B：以 synergy 为主，记为有限度的正向结果；
   - C：以 unique2 退化为主，暂不把 UniGIR 写成有效改进。
2. 后续是否补实验：
   - A：暂停训练，先完成论文结果和导师汇报；
   - B：只补一个有明确假设和独立指标的目标拆分短实验；
   - C：停止 UniGIR 主线，转向新的研究问题。
3. 论文材料的优先顺序：
   - A：先完成 G0 主表、unique2 退化图和表示诊断表；
   - B：先扩展一个新的真实任务；
   - C：先继续比较 queue、prototype 和 loss weight。
