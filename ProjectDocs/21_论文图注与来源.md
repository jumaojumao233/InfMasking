## Figure 1：G0 synergy ROC AUC

![G0 synergy ROC AUC by model seed](figures/figure1_g0_synergy_auc.png)

图注：G0 中三个 model seed 的 synergy ROC AUC。每个 seed 使用相同的数据和训练协议比较 Baseline 与 UniGIR，柱顶给出对应方法的 ROC AUC，`Δ` 表示 UniGIR 减 Baseline。三个 seed 的差值分别为 `+0.027`、`+0.037` 和 `+0.014`，平均差值为 `+0.026`。

用途：作为主要指标图，说明正向变化是否依赖某一个 seed。

限制：图中只展示 10 epoch G0 结果，不支持长训练收益的判断；synergy acc@1 的方向并非三个 seed 都为正，因此不能用这张图代表所有 synergy 指标。

## Figure 2：G0 unique2 固定变换配对评测

![G0 unique2 fixed-transform evaluation](figures/figure2_g0_unique2_fixed_eval.png)

图注：G0 六个 checkpoint 在固定 test transform 下的 unique2 配对评测。固定变换为 `Resize(256) + CenterCrop(224)`，每个 seed 处理 4214 个 pair，同一 seed 的 Baseline 与 UniGIR 使用相同的 pair 顺序。三 seed 的差值分别为 `-0.050308`、`-0.038681` 和 `-0.116516`，平均差值为 `-0.068502`。

用途：说明 unique2 退化在固定评测变换下仍然出现，排除随机裁剪是主要假象这一解释。

限制：这是一套独立只读评测，绝对 acc@1 不能和训练末 `by_fit` probing 的绝对值直接合并；该图支持配对差值判断，不提供机制因果证据。

## Figure 3：G0 texture 类别差值

![G0 texture-level changes](figures/figure3_g0_texture_deltas.png)

图注：不同 texture 类别上的 UniGIR 减 Baseline 差值。紫色表示训练末日志中的类别准确率平均差值，橙色表示固定变换配对评测中的 recall 平均差值。`pluses`、`stripes` 和 `zigzags` 在两套分析中都保持下降；`pluses` 在固定变换下平均下降 `-0.123`，训练末类别准确率平均下降 `-0.092`。

用途：展示 unique2 退化集中在哪些 texture 类别，并区分训练末统计和固定变换复核。

限制：两种颜色来自不同评测协议，不能把它们合并成单一统计检验；类别差值只能说明误差分布，不能证明 profile 目标造成了具体类别的错误。

## 复现命令

绘图只读取脚本中的已核对数字，不读取 checkpoint，不调用训练入口。轻薄本可使用临时 uv 环境执行：

```powershell
$env:UV_CACHE_DIR = Join-Path (Get-Location) '.uv_plot_cache'
$env:UV_PYTHON_INSTALL_DIR = Join-Path (Get-Location) '.uv_plot_python'
uv run --managed-python --no-project --python 3.11 --with matplotlib --with numpy python run_scripts/make_paper_figures.py --output-dir ProjectDocs/figures
```

- `ProjectDocs/figures/figure1_g0_synergy_auc.png`
- `ProjectDocs/figures/figure2_g0_unique2_fixed_eval.png`
- `ProjectDocs/figures/figure3_g0_texture_deltas.png`
