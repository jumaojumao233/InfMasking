# 阶段 1：融合关系结构失真诊断计划

更新时间：2026-09-26

## 1. 当前研究问题

InfMasking 通过随机遮挡制造不同的部分模态组合，使模型学习单个样本中的跨模态信息。当前需要先检查一个更具体的问题：遮挡增强是否会改变不同样本之间原本的融合关系。

本阶段研究问题写成：

> 在固定的 InfMasking checkpoint 上，随着测试时随机遮挡强度增加，完整融合表示中的全局样本关系是否发生系统性失真？

这里的直接测量对象是完整融合表示的关系结构。它只是全局协同结构的可操作代理，不能直接等同于真正的 synergy structure。当前文档、代码输出、图名和实验结论统一使用融合关系结构或 fusion relational structure，暂时不使用协同结构失真作为已经成立的结论。

## 2. 为什么先做诊断而不改模型

此前的 UniGIR V2 和 V3 都是在已有 InfMasking 上增加关系监督。V2 的 cosine profile 在 G0 上带来 synergy ROC AUC 的正向变化，但 unique2 持续下降；V3 的 geodesic profile 没有解决这个任务间权衡。这个结果提示当前最需要解释的是现象，而不是继续增加模块。

如果遮挡只是让每个样本的表示自然漂移，加入关系保持损失的动机就很弱。如果遮挡会在保持部分单样本信息的同时重排样本之间的关系，才有必要继续研究全局结构的定义和保护方式。因此第一阶段不修改训练目标、不增加 prototype、Sinkhorn、EMA、队列或 consistency 模块，也不重新训练多个 masking ratio。

## 3. 第一阶段的可操作定义

对固定样本集合中的第 (i) 个 pair，记完整融合投影为 (z_i^{\mathrm{full}})，测试时遮挡后的融合投影为 (z_i^{\mathrm{mask}})。完整关系矩阵和遮挡关系矩阵定义为

$$
R_{ij}^{\mathrm{full}}
=
\cos\left(z_i^{\mathrm{full}},z_j^{\mathrm{full}}\right),
$$

$$
R_{ij}^{\mathrm{mask}}
=
\cos\left(z_i^{\mathrm{mask}},z_j^{\mathrm{mask}}\right).
$$

将两个矩阵的非对角上三角元素展开，主指标为

$$
\rho_{\mathrm{rel}}
=
\operatorname{Spearman}
\left(
\operatorname{vec}_{\triangle}(R^{\mathrm{full}}),
\operatorname{vec}_{\triangle}(R^{\mathrm{mask}})
\right).
$$

这个指标回答的是：完整融合表示中的样本相对关系排序，在遮挡后保留了多少。它不能回答样本之间的真正跨模态交互模式是否被保留，后者属于第二阶段问题。

## 4. 固定实验协议

| 项目 | 固定设置 | 目的 |
|---|---|---|
| 数据 | G0：`trifeatures_g0_seed20260924` | 先控制数据版本，不扩展数据集 |
| checkpoint | 固定的 InfMasking Baseline checkpoint，model seed=42 | 排除不同训练结果造成的混淆 |
| pair 协议 | `Sup + biased=false + task=unique2` | 与已有 unique2 诊断使用同一类固定测试 pair |
| pair 数量 | 256 个，所有比例和 seed 共用 | 控制运行时间并保证配对比较 |
| 图像变换 | `Resize(256) + CenterCrop(224) + ToTensor + ImageNetNormalize` | 消除评测时随机裁剪 |
| masking ratio | `0、0.1、0.3、0.5、0.7、0.9` | 覆盖无、轻、中、重遮挡 |
| mask seed | `101、202、303、404、505`，共 5 个 | 估计随机遮挡带来的均值和标准差 |
| masked view | 使用模型当前的 3 个 masked views，逐 view 记录 | 保留 view 级随机性，不只保存平均向量 |
| 训练 | 不重新训练，固定 checkpoint 只做测试时改变 ratio | 这是敏感性诊断，不是 masking ratio 调参实验 |
| 输出 | 独立目录、JSON、CSV、关系矩阵和样本清单 | 支持复核和后续作图 |

测试时只改变 `fusion_transformer.mask_ratio`。完整融合表示来自同一 checkpoint，样本集合和 DataLoader 顺序固定。每个 ratio 使用多个 mask seed；每个 seed 的多个 masked view 单独计算，再在汇总表中报告均值和标准差。

## 5. 指标和结果表

主指标：

1. 融合关系 Spearman 相关 `spearman_relation`；
2. Top-5、Top-10、Top-20 邻居保持率；
3. 样本自身的 `cos(z_i^{full}, z_i^{mask})`。

关系保持指标和样本自身 cosine 需要同时看。前者下降而后者仍较高，才说明单个样本向量的变化不能完全解释样本关系的重排；如果两者都按相同比例下降，只能说明表示对遮挡敏感，不能进一步声称存在结构特异性代价。

## 6. 运行实现和文件

新增脚本：`run_scripts/diagnose_fusion_relation_structure.py`。

脚本职责：

- 加载固定 checkpoint 和固定 G0 数据；
- 生成一次完整表示和样本清单；
- 对每个 ratio、mask seed 和 masked view 计算关系指标；
- 输出 `diagnostics.json`、`relation_metrics.csv`、`relation_summary.csv`、`full_relation.npy` 和 `full_embeddings.npy`；
- 不调用 `trainer.fit()`，不更新模型参数、prototype 或 queue。

指标函数的最小测试位于 `tests/test_fusion_relation_structure_diagnostic.py`。测试覆盖关系矩阵、Spearman、邻居保持率、full-mask cosine 和非法 Top-k 参数。

远端运行使用 winpc 的固定项目环境和独立目录。启动前检查 checkpoint、G0 数据、GPU、磁盘和已有 Python 进程；运行中不停止其他任务，不覆盖旧实验；结束后检查退出码、日志、输出文件和 GPU 释放状态。

## 7. 阶段门

第一阶段不设置固定的数值阈值，主要检查以下三个性质：

| 检查 | 通过时的含义 | 不通过时的处理 |
|---|---|---|
| ratio 增大时关系指标是否有稳定趋势 | 存在需要解释的融合关系敏感性 | 只记录表示变化，不升级研究主线 |
| 不同 mask seed 的趋势是否相近 | 现象不是单个随机 mask 造成 | 增加 seed 或停止解释 |
| 关系指标与 full-mask cosine 是否可区分 | 可能存在关系重排，而不只是样本向量漂移 | 只能称为表示敏感性 |

如果得到稳定的关系下降，再进入第二阶段，分别比较普通融合语义结构、单模态结构和交互签名结构。只有后续能证明交互结构的变化明显区别于普通表示变化，才可以把研究问题升级为跨模态协同结构失真。

## 8. 当前边界和下一步

第一阶段结果已经完成，不能把 V2 的 unique2 下降解释为关系结构失真。第一步的关系曲线和数字审计已经完成；第二步的普通融合、单模态和简单交互签名对照已经完成；第三步的非加性残差诊断也已经完成。当前阶段的直接测量仍然只是融合关系结构，后续文档不得把它升级为已经测到 synergy structure。

简单交互签名和非加性残差都没有通过第二层区分，因此我不实现 V4，不继续 V3 的大范围搜索，不启动 100 epoch，也不在当前 checkpoint 上继续试表示差分或残差代理。

## 10. 交互签名可行性诊断的结果

我进一步比较了完整融合、两个单模态分支和交互增量签名。交互增量签名为

$$
s_i=\left[
\operatorname{norm}(h_i^{ab}-h_i^a),
\operatorname{norm}(h_i^{ab}-h_i^b)
\right].
$$

在 ratio=0.9 时，四类表示的 Spearman、Top-5 和 full-mask cosine 如下：

| 表示 | Spearman | Top-5 | full-mask cosine |
|---|---:|---:|---:|
| fusion | 0.9282 | 0.6424 | 0.9868 |
| mod1 | 0.9025 | 0.6213 | 0.9746 |
| mod2 | 0.9117 | 0.6340 | 0.9819 |
| interaction | 0.8840 | 0.4838 | 0.8519 |

interaction 的关系指标下降更明显，但自身 cosine 也显著下降，不能把它解释成协同结构特异失真。这个代理不通过第二层阶段门，当前不进入论文主指标。

下一步改为非加性残差代理：用训练 pair 拟合 `h_ab` 对 `[h_a;h_b]` 的 ridge 线性基线，在留出 pair 上计算 `r=h_ab-\hat h_ab`，再比较 residual relation。这个步骤仍然只做诊断，不改训练目标。

## 12. 阶段门关闭与研究计划调整

阶段 1 可以保留为一项已完成的融合关系敏感性诊断：固定 checkpoint 下，mask ratio 增大时，关系 Spearman、Top-k 邻居保持率和 full-mask cosine 均下降，并且关系重排比单个样本的 cosine 下降更明显。

阶段 2 不成立为协同结构证据。简单差分签名和 Ridge 非加性残差都受到自身表示不稳定性的影响，不能证明关系变化主要来自跨模态 synergy。当前研究计划调整为：

1. 冻结阶段 1—3 的结果和代码，完成数字、日志和文档的独立审计；
2. 继续以 V2-Cosine 作为主线候选，以 V3-Geodesic 作为负向对照，不实现 V4；
3. 将融合关系敏感性写成已观察现象，把协同结构解释保留为未验证假设；
4. 如果以后重新研究协同结构，先定义带反事实或信息分解依据的交互量，再重新设计控制实验。
