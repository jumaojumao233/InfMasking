# 第一部分：Idea 修订说明

## 1. 修订总览（先看结论）

| 维度 | 原 idea (v0) | 修订后 (v1) | 原因 |
|---|---|---|---|
| **第一卖点** | 首次将**测地距离**引入多模态对比学习，纠正球面/流形失配 | **全局关系结构感知的协同学习**：掩码视图需预测自己在全局原型拓扑中的位置；测地距离降级为增强项 | GeoMM (CVPR 2025) 已发表"测地替换余弦 + 聚类中心 Floyd 最短路"，首发性丧失（详见 3.1） |
| **全局结构来源** | Indra 式样本级关系轮廓，O(n²) | **原型级**（K 个地标）软分配轮廓，O(B×K) | 与 GeoMM/Indra 差异化 + 可训练 |
| **原型/地标生成** | 冻结预训练编码器 + **离线 k-means**（一次性） | **在线** EMA 原型库 + Sinkhorn 均衡分配（无需预训练模型，从头训练可用） | Trifeatures/多模态库大多从头训练，无"冻结预训练编码器"可用；离线原型与训练特征存在空间漂移 |
| **测地距离的角色** | 损失中所有相似度的替代度量 | **V3 增强项**（原型图最短路径），与 V2（软分配轮廓）消融对照 | batch 内测地距离数学上未定义；需先验证"全局结构对齐"本身的价值 |
| **验证优先序** | 合成（Trifeature）→ MultiBench | 同左，但**先跑 S 组（biased=true）** | R-U 组（biased=false）的 synergy 任务恒为随机水平，无法检验协同信息（见 4.2） |
| **输出形态** | 特征 z + 关系轮廓 Profile(z) | 同左（轮廓 = 对 K 原型软分配，推理时可廉价计算） | 未变 |

## 2. 不变的部分（继承自 v0）

- **任务定义**：协同信息（synergy）是多模态学习中被忽略的信息维度，需要显式建模——仍成立
- **掩码协同框架**：继承 InfMasking 的无限掩码（随机 token 掩码 70-80%、多掩码视图、融合 Transformer），作为底座
- **总损失骨架**：L_total = 局部对齐 + 跨模态协同 + α·L_global；α 可调
- **评测体系**：Trifeature（share/unique1/unique2/synergy probing）+ MultiBench 真实数据 + 消融 + 鲁棒性 + 可视化
- **投稿目标**：ACM Multimedia 2027（Multimodal Fusion）
- **推理用法**：冻结 backbone + 轻量分类头；轮廓可用于检索/跨模态对齐

## 3. 三处重要修订及理由

### 3.1 定位修订：为什么不再主打"测地距离首发性"
核查三篇关键论文后：
- **GeoMM (CVPR 2025)**：已提出测地距离替换余弦用于图像-文本对比学习，做法为 **k-NN 图 + Floyd 最短路 + 分层 K-means 压缩（在聚类中心上算）+ 增量更新**，动机与 v0 几乎逐句相同
- **Indra (NeurIPS 2025)**：Yoneda 嵌入构建样本级关系轮廓，O(n²) 推理用（本地有官方代码）
- **InfMasking (NeurIPS 2025 Spotlight)**：本项目底座，本地已复现

→ 若仍主打"测地首发性"，审稿人必引 GeoMM 拒稿。剩余未被占用的空间是 **"全局关系结构作为协同学习的训练目标"**——GeoMM 无掩码协同框架、无轮廓对齐目标；InfMasking 无全局结构。**新卖点：协同信息 = 跨模态共享的全局关系结构，局部 batch 内对比（余弦）无法捕捉，故用原型级轮廓对齐显式建模之。** 测地距离保留为与 GeoMM 对照的增强项（V3），证明"度量选对了能更好"而非"首个用测地"。

### 3.2 方法修订：全局轮廓的工程形态
| v0 写法 | 问题 | v1 修订 |
|---|---|---|
| 每样本到 K 个聚类中心的**测地距离**向量 Profile(z) = [d_g(z,c_k)] | 测地距离只定义在图上节点间；z 与 c_k 之间**没有定义最短路径**（缺 attach 步骤） | 定义明确的两步：样本 z →（k-NN/最近中心）attach 到原型图 → 图内最短路径得距离；V2 先用**软分配**（Sinkhorn 码）当轮廓 |
| batch 内 $d_g(z_a,z_b)$ 参与 InfoNCE | batch 仅 64-128 点，无法建可靠图 | **放弃 batch 内测地**；局部对齐沿用余弦，测地只用于原型级轮廓 |
| 冻结预训练编码器（如 CLIP）离线建原型 | Trifeatures 等多模态库**无预训练可用**（从头训练） | **在线原型库**：每步对完整视图做 Sinkhorn 均衡分配 → EMA 更新 K 个 L2 原型；掩码视图以 KL 损失预测完整视图的分配码 |
| 掩码视图轮廓 → 完整视图轮廓回归（MSE） | 分布形态不对齐 | KL( codes(full) ‖ softmax(mask·Pᵀ/τ) )，六个掩码视图共同监督 |

### 3.3 实验修订：先验证哪张桌
- v0 在 Trifeature 上同时跑 R-U（biased=false）与 S（biased=true）两组
- 实测发现：**R-U 组 synergy 任务恒为 ~0.5（随机）**——biased=false 时 synergy 属性无相关结构，无协同信息可学
- v1 决定：**协同增益必须在 S 组（biased=true，texture-color 人为相关）验证**，R-U 组用于检验不损害冗余/独有能力
- 消融优先级：① L_global 有无（S 组）② V2 软分配 vs V3 测地轮廓 ③ K、α、τ 敏感性 ④ 掩码比例×度量交互

## 4. 已实现内容（v1 的 V2 子版本，代码在工作区）

### 4.1 代码清单
| 文件 | 内容 |
|---|---|

### 4.2 首轮实验结果（CPU，4 epochs，seed 42，biased=false，max_size=1024）
- Baseline（InfMasking）mean acc1：0.304 → 0.338 → 0.353 → **0.372**
- UniGIR（V2）mean acc1：0.309 → 0.339 → 0.345 → **0.355**
- profile 机制本身有效：掩码视图预测全局原型位置准确率 0.159 → **0.373**（K=512 时随机仅 0.2%）
- **解读**：机制在学、训练稳定、无 NaN；但 R-U 短跑下游无增益（差异在评测噪声内），且 synergy 在该组恒为随机 → **尚不能判定方法无效，需 S 组验证（下一步）**

### 4.3 未实现（按 v1 优先级排队）
1. S 组（biased=true）对照 —— 检验协同增益的关键实验（CPU 约 2h/组，可后台）
2. V3 测地轮廓（原型图 + 最短路径 + 定期重构图）
3. α/K/τ 消融、更长训练（10+ epochs）
4. 鲁棒性（丢模态/加噪）与可视化（轮廓 t-SNE、原型热力图）
5. MultiBench 真实数据（需下载数据，多数据集需注册/许可）
