## 一、项目概况

InfMasking 是一个**多模态自监督表征学习**框架：

- 对多个模态（图像等）做**随机 token 掩码**，并让掩码视图的表征与完整视图对齐（掩码重建损失）
- 联合 **InfoNCE 类对比损失**（模态内/模态间）
- 通过下游 **linear probing** 评测学到表征的质量，关注属性的 **冗余性（R-U）与协同性（Synergy）**

官方代码内含多个数据集入口（Trifeatures 合成数据、Hateful Memes、MMIMDb 等），当前阶段复现的是 **Trifeatures 合成数据集（BimodalTrifeatures）** 上的两组实验：
- `biased=false`（R-U：属性无偏相关）→ 评测 share / unique1 / unique2 任务
- `biased=true`（Synergy：两个属性人为相关）→ 额外评测 synergy 任务

# 更新（2026-09-09 晚间）：创新工作 UniGIR 已启动

## 进展（在复现基础上的延伸）
1. **创新方向**：基于 InfMasking 提出 **UniGIR**（投稿目标 ACM Multimedia 2027，Multimodal Fusion）——让模型在掩码协同学习中同时感知**全局关系结构**（原型级轮廓对齐）
2. **定位调整（重要）**：原始想法主打"首次用测地距离替换余弦相似度"，但经查证 **GeoMM (CVPR 2025) 已发表该做法**（k-NN 图 + 聚类中心 Floyd + 增量更新）。已将卖点转向 **"全局关系结构感知的协同学习"**——掩码视图预测自己在全局原型拓扑中的位置（借鉴 Indra 关系轮廓思想，O(n²)→O(K²) 在线化），测地距离作为与 GeoMM 对照的增强项
3. **V2 已实现并跑通**（本机 CPU）：
   - 新增 `../losses/prototype_alignment.py`：512 原型 + Sinkhorn 均衡分配 + 掩码→完整视图 KL 对齐 + EMA 在线更新（不需要冻结预训练编码器）
   - 新增 `../configs/model/unigir.yaml`，一行启用；不启用时与原 InfMasking 行为一致
4. **首轮对照**（4 epochs，seed 42，biased=false，CPU 减配）：
   - Baseline acc1 0.304→0.372；UniGIR 0.309→0.355
   - profile 机制本身有效（预测准确率 0.159→0.373，随机 0.2%），但 **R-U 组下游暂未体现增益**
