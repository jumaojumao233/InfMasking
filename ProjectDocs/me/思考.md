# 2. 当前科学问题

InfMasking 已经通过多模态 masking，使 masked view 与 full view 保持信息联系，并重点学习 multimodal synergy。

UniGIR 当前需要回答的科学问题是：

> **现有 InfMasking 主要约束样本级 masked/full representation consistency，但缺少对样本在更大数据分布中的 relational position 的显式约束。**

UniGIR 希望建立一个动态的 global relational space，使：

- full multimodal view 描述样本在全局结构中的位置；
- masked multimodal view 不仅恢复样本自身表示；
- 还要恢复其相对于全局数据结构的 relational profile。

推荐的核心概念表达：

> **Global Relational Structure Distillation under Multimodal Masking**

不要把论文故事写成：

> Prototype + Sinkhorn + EMA + Queue。

这些都是成熟组件，本身不足以构成主要创新。

# 3. 当前方法概念

现阶段方法包括：

1. 原始 InfMasking objective；
2. 建立 K 个 global prototypes；
3. full view 与 prototypes 计算关系；
4. Sinkhorn 得到 balanced assignment；
5. masked view 预测 full view 的 relational/profile distribution；
6. 通过 KL/profile loss 对齐两者。

当前形式：

$$
\mathcal{L}
=
\mathcal{L}_{\mathrm{InfMasking}}
+
\alpha\mathcal{L}_{\mathrm{profile}}.
$$

当前候选参数：

- 单向预测；
- K = 128；
- queue = 1024；
- α = 0.25；
- prototype dim = 256；
- prediction temperature ≈ 0.1。

在下一轮核心验证完成之前：

> **不要进行大规模超参数搜索。**

------

# 4. 当前最重要的风险

目前最大的科研风险是：

> **Profile task 本身可能学得很好，但它学习的信息对 downstream multimodal synergy 没有实际价值。**

旧实验中出现了一个值得重点调查的现象：

queue=1024 时：

- profile accuracy ≈ 0.698；
- 但 downstream 平均 acc 只比 queue=0 小幅提升。

这可能有两种解释。

## 情况 A：方法成立

masked view 能稳定恢复 full view 的 global relational structure。

如果这种能力与：

- synergy accuracy；
- synergy ROC-AUC；
- downstream performance；
- neighborhood preservation

存在稳定正相关，则论文故事可以成立。

## 情况 B：辅助任务是伪目标

profile assignment 很容易预测，但与真正 downstream task 无关。

那么会出现：

> profile loss 学得很好
> → profile accuracy 很高
> → downstream 不涨

这种情况下不能靠继续调 K、α、queue 去强行救方法。

必须重新考虑 objective 是否真正对应 multimodal synergy。

# 7. 第一阶段 Go / No-Go 标准

重点观察：

- synergy acc@1；
- synergy ROC-AUC；
- 所有 downstream task；
- profile loss；
- profile accuracy；
- prototype utilization；
- assignment entropy；
- representation statistics。

### 强 Go 信号

例如：

- 3/3 seed synergy 指标提升；
- 平均提升具有实际幅度；
- 不以明显牺牲其他任务为代价；
- profile branch 学习稳定。

结论：

> 立即进入机制验证。

### 弱 Go 信号

例如：

- 2/3 seed 提升；
- 平均结果正向；
- 方差可接受；
- 某一 seed 小幅失败但总体趋势存在。

结论：

> 可以进入有限机制验证，但暂时不要跑完整大实验。

### No-Go / 高风险信号

例如：

- 只有 1/3 seed 提升；
- 结果方向随机；
- synergy 涨、其他指标普遍明显下降；
- profile accuracy 很高但所有 downstream 基本不变；
- queue/prototype 极不稳定。

结论：

> 暂停 UniGIR 主线，不进入100 epoch和大规模实验。

# 8. 第二阶段：机制验证

这一阶段用于检验：

> **收益是否来自 global relational profile，而非普通 auxiliary regularization。**

必须设计能够回答审稿人质疑的 control experiments。

建议优先级如下。

## 8.1 正常 UniGIR

full-view global relational profile → masked-view prediction。

作为正式方法。

## 8.2 Shuffled Profile

打乱 full-view relational target。

目的：

> 排除“只要多一个loss就能 regularize”的解释。

如果 shuffled profile 与 UniGIR 表现相近，则 UniGIR 核心理论非常危险。

## 8.3 Random Prototype Target

使用随机或无语义 prototype assignment。

目的：

> 验证 prototype structure 本身是否提供有效信息。

## 8.4 No Queue

queue = 0。

目的：

> 验证更大范围 global memory 是否必要。

这是核心消融，必须保留。

## 8.5 No Sinkhorn / Naive Softmax

不用 balanced assignment。

目的：

> 判断 Sinkhorn 是否只是工程组件，还是防止 prototype collapse 的关键。

## 8.6 Batch-only Relational Profile

只使用当前 batch 内关系，不使用 global queue/prototype structure。

这是非常重要的 control。

如果：

global relational profile > batch-only relation

则可以直接支持核心论点：

> **跨 batch 的 global relational information 提供了 InfMasking 原本缺失的结构信息。**

当前实现中 `queue=0` 已经表示只在当前 batch 上做 Sinkhorn。因此 No Queue 与 Batch-only Relational Profile 在现有代码里是同一个干预，不能作为两项独立消融。只有在重新定义 batch-only 关系目标后，二者才可分开报告。

推荐优先考虑 InfMasking 原论文已经使用的数据集，优先选择训练成本低的数据集。

首选可考虑：

> MOSI

原因：

- 数据规模相对较小；
- 真实 audio + vision + text；
- 原 InfMasking 已有结果；

MOSI 的标签是情感分类标签，没有直接的 synergy 标注。它可以检验真实任务迁移和整体效用，不能单独证明 UniGIR 提高了 synergy。机制结论仍需依赖合成任务、对照实验和表征分析。

# 10. 真实数据 Go / No-Go

这是 UniGIR 是否正式成为论文主线的关键门。

## 强 Go

例如：

- 多个 seed 上 UniGIR 稳定优于 InfMasking；
- 提升不是只存在于某一个指标；
- 没有显著负迁移；
- mechanism metric 与 downstream improvement 有对应关系。

结论：

> UniGIR 正式升级为论文主线。

开始：

- 完整实验；
- 多 benchmark；
- 正式写作；
- 图表设计。

## 弱 Go

真实数据只有很小提升，但趋势稳定。

结论：

> 继续测试第二个真实数据集。

如果第二个 benchmark 仍只有极弱收益，需要重新评估 novelty 与投入产出比。

## No-Go

例如：

- Trifeature 涨；
- MOSI 不涨甚至下降；
- profile accuracy 很高；
- downstream 没有收益。

结论：

> 不要继续大量调参。

优先判断：

1. scientific hypothesis 是否错误；
2. profile objective 是否与 synergy 不一致；
3. 是否应该停止 UniGIR 并寻找新的 candidate idea。

# 14. 创新性写作原则

禁止将 contribution 写成：

1. 我们使用 prototypes；
2. 我们使用 Sinkhorn；
3. 我们加入 queue；
4. 我们加入 KL loss。

这种写法极易被认为是已有组件拼装。

应该围绕 scientific question：

### Contribution 1

发现现有 masked multimodal learning 主要关注 instance-level information preservation，但忽视 global relational position。

### Contribution 2

提出一种 global relational structure distillation mechanism，使 masked multimodal representation 保留 full multimodal sample 在全局数据结构中的位置。

### Contribution 3

通过 synthetic synergy benchmark + 多个真实 multimodal benchmark 证明：

global relational preservation 能进一步增强 multimodal synergistic representation。

### Contribution 4

通过 control experiments 与 representation analysis 证明：

收益应能归因于有意义的 global relational information，并排除普通 auxiliary regularization 的解释。

- 不允许基于 test 调参；

Baseline 与 UniGIR：

- 相同 seed；
- 相同 dataloader order；
- 相同初始化条件；
- UniGIR 自有随机操作不得污染 baseline 的 RNG。

## 原则 4：每次实验回答一个问题

任何实验开始前必须明确：

> Hypothesis：

> Experiment：

> Expected outcome：

> Interpretation if positive：

> Interpretation if negative：

如果无法回答这五项，不建议运行实验。

## 原则 5：及时建议终止

Agent 不应默认帮助 UniGIR“继续优化”。

如果证据显示：

- 真实数据不成立；
- mechanism control 失败；
- 方法只能产生辅助任务收益；
- novelty 难以建立；

应该主动建议：

> **停止 UniGIR，寻找新 candidate idea。**

## 原则 6：不要被沉没成本影响

已经投入的时间不作为继续研究的理由。

唯一判断标准：

> 从现在开始继续投入 UniGIR，是否仍然是最快获得 CCF-A 的高期望值路径。
