# UniGIR 研究心路历程

更新时间：2026-09-26

这份文档记录研究为什么从 InfMasking 走到 UniGIR V2、V3，以及当前为什么开始考虑信息类型感知的关系蒸馏。它区分已经完成的工作、实验得到的结果和还没有验证的想法，后续每次出现新的实验现象或方法判断，都继续追加到这里。

## 0. 2026-09-26：从组件组合转向先验证现象

前面的路线是从 InfMasking 出发，依次尝试 prototype profile、Sinkhorn、EMA、queue 和 geodesic prototype graph。V2 在 G0 的 synergy 任务上有正向信号，但 unique2 稳定下降；V3 没有解决这个权衡。因此当前不能继续把问题表述成加入哪一个新模块更有效。

新的研究假设是：InfMasking 可能提高单个样本能够利用的跨模态信息丰富性，但在随机遮挡下改变样本之间交互模式的组织关系。这个假设仍未验证。为了避免概念提前变大，第一阶段只测量固定 checkpoint 下的融合表示关系结构，用它作为全局协同结构的代理，不直接称为 synergy structure。

第一阶段使用完整融合表示和 masked 融合表示的 cosine 关系矩阵，按 mask ratio 和随机 mask seed 计算 Spearman、Top-k 邻居保持率以及 full-mask cosine。这里的判断重点是：关系变化是否有稳定趋势，是否跨随机 mask seed 重现，是否能和样本自身表示漂移区分。只有这三个条件大致成立，才进入下一阶段分离普通语义、单模态和真正交互成分。

## 0.1 2026-09-26：第一阶段确实观察到融合关系重排

固定 G0 InfMasking checkpoint 后，关系诊断得到清楚的单调趋势。mask ratio 从 `0` 增加到 `0.9` 时，Spearman 从 `1.0000` 降到 `0.8466`，Top-5 邻居保持率从 `1.0000` 降到 `0.6048`，full-mask cosine 从 `1.0000` 降到 `0.9039`。五个 mask seed 和三个 masked view 的标准差较小，说明这个趋势不是单个随机 mask 造成的。

这个结果比简单的表示距离下降更有信息：ratio=0.9 时，样本自身仍保持约 `0.904` 的 cosine，但最邻近样本只有约 `0.605` 被保留，说明样本间关系发生了额外重排。它支持继续研究融合关系结构，但还没有回答关系重排是否主要来自跨模态交互成分。当前最重要的下一步是建立普通融合、单模态和交互签名三类对照，不急着把现象包装成新模块的动机。

## 1. 从 InfMasking 开始：先解决缺失信息的问题

项目的起点是 InfMasking。它的基本训练方式是从同一个完整样本生成完整视图和多个掩码视图，让模型在不完整输入下恢复完整输入中的协同信息。训练目标包含 InfoNCE、掩码视图之间的协同约束和跨模态表示学习。

这个起点解决的是局部问题：掩码视图应该尽量接近对应的完整视图，并且利用仍然存在的模态推断缺失信息。但仅靠样本之间的对比关系，模型缺少一个全局参照系。模型知道某个掩码视图应该接近哪个完整样本，却不一定知道它在所有样本形成的表示空间中处于什么位置。

因此最初的想法是引入一组在线 prototype。完整视图不只给出自己的表征，还给出自己与一组全局 prototype 的关系；掩码视图学习恢复这个关系。这样，完整视图可以用一组全局地标描述，掩码视图需要恢复自己在这些地标之间的位置。

在工程上，我先完成了训练入口、独立日志、checkpoint、断点续跑、winpc 计划任务和邮件 watchdog。轻薄本只负责 SSH、日志、CPU 统计、文档和邮件，实验训练放在 winpc。这个过程看起来是工程准备，但它直接决定后面的实验能否复核：每个运行有独立目录，每个 epoch 保存 `last.ckpt`，失败时不会覆盖其他 seed 的结果。

## 2. V2-Cosine：用 prototype profile 建立全局关系

V2 在 InfMasking 上加入 prototype 全局关系轮廓。设在线 prototype 为

$$
P=\{p_1,\ldots,p_K\}.
$$

完整视图根据表征和 prototype 的余弦关系生成 target profile，掩码视图用 softmax 预测这个 profile。完整视图的 target 经过 Sinkhorn 平衡分配并 detach，prototype 通过 EMA 更新。对应的监督可以写成

$$
\mathcal{L}_{\mathrm{profile}}^{\mathrm{cos}}
=
\frac{1}{T}\sum_{t=1}^{T}
\operatorname{KL}
\left(q_i^{\mathrm{full}}\middle\Vert p_{i,t}^{\mathrm{mask}}\right).
$$

V2 的动机是合理的，但创新强度有限。prototype、Sinkhorn、KL 蒸馏和 EMA 都是已有组件，当前方法的组合主要服务于掩码信息恢复。

G0 三个 seed 的结果给出了一个很关键的现象：UniGIR 的 synergy ROC AUC 在三个 seed 上都提高，平均提高约 `0.026`；但 unique2 Acc@1 在三个 seed 上都下降，平均下降约 `0.053`。固定 test transform 后，unique2 的配对平均差值约为 `-0.0685`，所以这个下降不能主要归结为随机裁剪。

这说明 V2 的问题不是简单的训练失败。它确实改变了表示，并且在共享协同任务上有收益，但这种全局关系监督可能压低了模态特有信息的线性可分性。profile 聚合指标没有显示明显的 prototype collapse，三个 seed 的 profile 都在工作；梯度诊断也没有发现跨 seed 稳定的全局梯度反向，只看到 batch 和 seed 相关的局部冲突。因此当前不能简单地说 profile 没有学到，也不能直接证明 profile 单独造成了某个 texture 类别的错误。

V2 的结论最终记为 `Uncertain`。它支持继续研究全局关系监督，但不支持直接进行长训练或无目标的 loss weight、queue、prototype 数量搜索。

## 3. V3-Geodesic：从全局地标关系走向流形关系

V2 使用余弦关系时，prototype 之间被当作相互独立的参照点。完整的 UniGIR idea 进一步提出，把 prototype 连接成图，在图上计算 shortest path，用 prototype graph 上的测地距离描述全局关系：

$$
G=(P,E),
$$

$$
D_G(j,k)=
\min_{\pi:j\rightarrow k}
\sum_{(u,v)\in\pi}w_{uv}.
$$

样本到 prototype 的近似测地距离可以写成

$$
d_G(z_i,p_k)
=
\min_{j\in\mathcal{N}(z_i)}
\left[
\lVert z_i-p_j\rVert_2+D_G(j,k)
\right].
$$

V3 用完整视图的 geodesic profile 指导掩码视图恢复：

$$
\mathcal{L}_{\mathrm{global}}
=
\operatorname{KL}
\left(q_{i,\mathrm{geo}}^{\mathrm{full}}
\middle\Vert
p_{i,\mathrm{geo}}^{\mathrm{mask}}
\right).
$$

V3 的研究价值比 V2 更清楚，因为它改变了全局关系的定义。但测地距离本身已经出现在已有多模态学习工作中，所以论文不能把第一次使用 geodesic distance 作为主要贡献。更准确的主张是：把 prototype graph 上的测地关系转成完整视图到掩码视图的关系蒸馏目标，并把它接入 InfMasking。

V3 的实验过程也暴露了实现和研究判断之间的关系。第一轮 V3 的 Sinkhorn 指数化发生浮点下溢，profile loss、KL 和 active prototypes 全为 0。那一轮虽然退出码为 0，但没有真正训练 geodesic profile，结果作废。我随后在指数化前做 row-wise max subtraction，并增加非零 profile 回归测试。

修复版 seed=42 正常完成。profile loss、profile KL、active prototypes 和 graph 连通性均正常，但四任务平均 Acc/AUC 比 V2 低 `0.0229/0.0079`，synergy AUC 低 `0.0229`，unique2 Acc 低 `0.0316`。因此 V3 在这个 seed 上是有效但负向的 geodesic 对照。

为了判断这个结果是否可重复，我又启动了 seed=7 的同协议复核。V2 seed=7 成功完成，四任务平均 Acc/AUC 为 `0.7671/0.9375`；V3 seed=7 在 epoch 7 附近出现 `CUDA error: an illegal memory access was encountered`，最终退出码为 `1`。失败前 profile 指标仍然非零，graph 也连通，但没有最终 probing 结果。这个 checkpoint 不能加入 V2/V3 性能比较，也不能直接恢复。

因此当前不能写出 V3 跨 seed 的最终结论。现在已经确认两点：

1. V3 的数值下溢问题已经修复，geodesic profile 可以正常产生训练信号。
2. V3 的第二个 seed 运行失败，且失败位置还没有定位，不能把 seed=42 的负向结果扩展成稳定结论。

下一步若继续 V3，只做带 `CUDA_LAUNCH_BLOCKING=1` 的独立短 smoke，先定位 graph 构造、`torch.cdist`、索引操作或 profile prediction 的具体触发算子。当前不直接重启失败任务，也不启动第三个 seed。

## 4. 当前真正暴露出的研究问题

目前最有价值的现象不是 V2 或 V3 的某一个绝对分数，而是关系监督可能带来任务权衡：全局关系恢复有助于 synergy，却可能牺牲 unique2。V3 是否使用 cosine 或 geodesic，首先要回答的是它会不会改变这种权衡。

如果 V3 仍然提升 synergy、牺牲 unique2，那么继续增加 graph 层数、prototype 数量或 Sinkhorn 细节，不能直接解决核心问题。问题已经从全局关系是否存在，转向全局协同关系和模态特有信息如何同时保留。

这也是当前不能立刻堆模块的原因。V2 和 V3 还没有形成完整、稳定的跨 seed 对照；如果没有先把 V3 的 CUDA 失败定位清楚，直接实现 V4 会把训练失败、距离定义和新增损失混在一起，最后无法判断结果来自哪一部分。

## 5. V4 的启发：信息类型感知的全局关系蒸馏

我认为最值得准备的方向是信息类型感知的全局关系蒸馏。核心问题是：

> 如何让掩码视图同时恢复完整视图的全局协同关系和模态特有信息？

V4 不把 unique loss 当作孤立的附加项，而是把完整视图提供的教师信号拆成两类。

### 5.1 全局关系教师

完整视图用 prototype graph 生成 geodesic profile，掩码视图恢复整体流形位置：

$$
\mathcal{L}_{\mathrm{global}}
=
\frac{1}{T}\sum_{t=1}^{T}
\operatorname{KL}
\left(
q_{i,\mathrm{geo}}^{\mathrm{full}}
\middle\Vert
p_{i,t,\mathrm{geo}}^{\mathrm{mask}}
\right).
$$

### 5.2 模态特有信息教师

一种实现是为每个模态建立单独的 prototype profile。对模态 $m$，完整视图产生 $q_{i,m}^{\mathrm{full}}$，掩码视图产生 $p_{i,t,m}^{\mathrm{mask}}$：

$$
\mathcal{L}_{\mathrm{unique}}
=
\frac{1}{M T}
\sum_{m=1}^{M}\sum_{t=1}^{T}
\operatorname{KL}
\left(
q_{i,m}^{\mathrm{full}}
\middle\Vert
p_{i,t,m}^{\mathrm{mask}}
\right).
$$

另一种实现是使用去掉某个模态后的完整视图作为反事实教师，比较完整视图和去掉模态后的关系变化，再约束掩码视图保留这种模态特有差异。两种实现不应在第一版同时加入，否则难以判断结果来自单模态 prototype 还是反事实教师。

最终目标可以写成

$$
\mathcal{L}_{\mathrm{V4}}
=
\mathcal{L}_{\mathrm{InfMasking}}
+\alpha\mathcal{L}_{\mathrm{global}}
+\beta\mathcal{L}_{\mathrm{unique}}.
$$

真正的贡献点不在于多加一个 loss，而在于让关系蒸馏目标对应不同的信息类型。全局教师负责共享和协同结构，模态特有教师负责保护单模态仍然携带的判别方向。这样 V4 直接回应当前实验暴露出的 synergy 与 unique2 冲突。

### 5.3 样本级关系置信度

可以考虑一个较轻的辅助权重。若完整视图的 geodesic profile 过于不确定，则减少全局关系监督：

$$
w_i
=
1-
\frac{H(q_i^{\mathrm{geo}})}{\log K}.
$$

全局损失可以改为

$$
\mathcal{L}_{\mathrm{global}}^{\mathrm{weighted}}
=
\frac{1}{T}\sum_{t=1}^{T}
w_i\operatorname{KL}
\left(
q_{i,\mathrm{geo}}^{\mathrm{full}}
\middle\Vert
p_{i,t,\mathrm{geo}}^{\mathrm{mask}}
\right).
$$

这部分只能作为辅助机制。模态感知正则、uncertainty weighting 和相关蒸馏已有研究，不能把样本级权重单独写成主要贡献。

## 6. 相关工作对创新边界的提醒

CVPR 2026 的 DMIL 已经显式讨论 redundant、unique 和 synergistic information，并强调样本级信息类型的变化。因此论文不能主张第一次把三类信息分解出来。相关论文：

[Information-Theoretic Decomposition for Multimodal Interaction Learning，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Yang_Information-Theoretic_Decomposition_for_Multimodal_Interaction_Learning_CVPR_2026_paper.pdf)

ICCV 2025 的 CMAD 已经研究缺失模态下的 correlation-aware distillation 和 modality-aware regularization。因此单独增加 unique loss，或者单独使用动态 loss weight，也很难构成充分的主要贡献。相关论文：

[CMAD: Correlation-Aware and Modalities-Aware Distillation for Multimodal Sentiment Analysis with Missing Modalities，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Zhuang_CMAD_Correlation-Aware_and_Modalities-Aware_Distillation_for_Multimodal_Sentiment_Analysis_with_Missing_Modalities_ICCV_2025_paper.html)

UniGIR V4 更合理的差异应当是：在 InfMasking 的无限掩码训练中，使用完整多模态视图的全局 prototype graph 关系作为教师，同时显式保护模态特有关系，并用 unique2 与 synergy 的共同变化验证这种信息类型分工是否有效。

## 7. 固定的论文路线和决策门槛

当前路线可以固定为：

```text
InfMasking
    ↓
V2-Cosine：验证全局 prototype 关系是否有用
    ↓
V3-Geodesic：验证流形关系是否比余弦关系更合适
    ↓
V4：信息类型感知的关系蒸馏
    ├── 全局 geodesic profile
    └── unique information protection
```

V4 是否实现，取决于 V3 的有效证据：

| V3 结果 | 当前判断 | 后续行动 |
|---|---|---|
| synergy 提升，unique2 明显改善 | V3 已经解决主要冲突 | 以 V3 为主方法，不继续加 V4 |
| synergy 提升，unique2 仍下降 | 全局关系有收益，但信息类型冲突仍在 | 诊断完成后实现 V4 双重关系教师 |
| synergy 和 unique2 都没有提升 | geodesic 没有带来信息增益 | 重新评估 UniGIR 主线，不继续堆模块 |
| 只在一个 seed 上有效 | 证据不稳定 | 先补固定 seed 和机制检查，不实现 V4 |
| V3 因 CUDA 或实现问题失败 | 方法结果尚未形成 | 先修复和复现运行链路，不做性能判断 |

V4 第一版的验收应至少包含：InfMasking baseline、V2-Cosine、有效 V3-Geodesic、V4-global-only 和 V4-global-plus-unique。主要指标同时报告 synergy ROC AUC 和 unique2 固定变换 Acc@1，不能只报告整体平均值。若 V4 同时降低 synergy 和 unique2，或者只在单个 seed 上提升，就停止扩展。

## 8. 当前结论

从 InfMasking 开始，我先解决了掩码视图如何恢复完整视图的问题；V2 加入 prototype 全局关系，发现全局关系确实可能帮助 synergy，但同时带来 unique2 退化；V3 将关系从余弦推广到 prototype graph 的 geodesic，修复了初轮数值下溢后，在 seed=42 上得到有效但负向的结果，seed=7 则因 CUDA 非法内存访问失败。

因此当前最重要的研究问题已经从是否增加一个更复杂的距离，转为如何在缺失模态恢复中同时保留共享协同信息和模态特有信息。V4 的双重关系蒸馏是值得准备的方向，但它现在仍是条件性方案。先完成 V3 失败的独立诊断和有效性边界，再决定是否实现。

当前不立即堆模块，也不把 V4 写成已经验证的方法。先把问题、教师信号、独立指标和停止条件固定下来，后续实验才有清楚的归因关系。
